# 子技能之间传什么

通过稳定 ID、路径和原文定位传递已有证据，不复制整份 JD／文章到多个技能目录。

先按[共用数据目录](storage.md)定位历史库。每个子流程都接收同一个数据根目录的绝对路径，并使用 `storage.py resolve --root ...` 获取账本、watchlist 和基线路径；独立调用子技能时执行相同定位流程。相对证据引用从该根目录解析，不从当前聊天目录解析。首次初始化只补缺和登记，不改变已有数据，也不自动执行全部子流程。

| 提供方 | 必要上下文 | 可用于综合的结果 |
|---|---|---|
| `ai-jobs` | 公司／岗位／方向、招聘阶段、地区、历史材料或待搜索范围 | `job_key`、岗位链接与日期、要求原句／kind／定位、资格待确认项、样本分母 |
| `ai-tech-radar` | 技术主题、公司／团队、时间范围、工程或研究问题；规划实践时传入已有能力与资源约束，需要岗位映射时提供 job_key 与要求原句 | `material_id`、`work_id`、正文阅读范围、方法与结果证据、按需提供的岗位关系、已核验 repo/ref/path |
| `interview-collection` | 目标岗位与招聘阶段、技术差距、已有面经来源、本轮要采集还是只编排练习；项目问答按需传 `project_id/claim_id`、个人贡献、证据范围和待补问题 | 原题与出处、实际可读的练习结果／导出；自行拟题明确标记为练习 |
| 个人已有产物 | 用户提供的仓库／实验／工作记录和当前目标，已有 `goal_id/project_id/action_id` 及计划／复盘引用 | 个人贡献、已实现／已验证的能力与版本范围，尚无证据的自述与约束 |

总入口生成项目卡时，连接如下字段：

`目标能力 → job_key/用户目标 → material_id/work_id → repo + ref + module → 自己的改动 → 验收 → 实际结果`

已有个人项目继续复用其 `project_id/action_id`；成果梳理按[项目规划](projects.md#项目成果与面试主张)将实际结果连到稳定 `claim_id`、可说的主张与证据范围。总入口可组织项目叙述和明确标注的拟定追问；真实面经、题库和学习界面仍由 `interview-collection` 负责。外部技能缺失不影响成果梳理，不冒称已收集原题或读到练习进度。反馈按[进展续接](progress.md)回写同一根目录的个人索引与复盘，不重复存储来源正文。

没有 JD 的成长请求，以用户的真实工作目标替代 `job_key`。缺少工程或科研证据时可直接做岗位／面试任务，不把所有槽位填满当成完成条件。

交接包含实践候选时，同时保留应用／工具／组件的交付边界、最小可验收版本、数据与运行依赖、工作量依据和可选扩展。研究候选再保留：最近邻原文位置与未决比较、已覆盖的主张与拟检验差异、直接对照／资产状态、自然流程与受控诊断的结论边界，以及默认矩阵的独立分母、唯一产物／标签复用、预算假设和先导条件。缺少依据就标明待核，不由总入口补成事实。它们属于本轮分析交接，不要求给每条采集材料新增必填字段；简单复现不套用完整原创研究交接。总入口复用这些证据，负责最终排序、默认完成条件和多项行动的共享预算。

依据团队研究选方向时，雷达同时交接本轮团队／主题／时间范围、实际覆盖与缺口，以及“团队及归属证据 → 具体工作与日期 → 研究观察 → 推荐方向或候选”的关系。范围内团队材料与用于比较的外部相关工作分别标明作用。总入口据此比较方向，再按个人条件选择切口；只有论文／仓库列表而没有这条依据时，不能直接给出团队导向的优先推荐。

一份论文、它的官方博客和代码仓库共享同一个 `work_id`，分别保留材料 ID；跨模态三份材料不是三个独立成果。历史 JD 与新文章时间不同，保留日期，关联表示能力相通，不证明新文章就是该职位的实际工作。

外部面经技能使用当前有效安装或用户指定的技能入口。

## 固定 list 的跨技能协同

用户说“关注某公司”时按本轮目的将它加入岗位和／或技术来源清单，复用同一公司名称与已核实别名；没有公开招聘入口的 Lab 仍可独立跟踪研究。总入口不维护第三份来源数据库，也不把技术来源自动视作招聘证据。请求“新增 list 来源”只更新范围，不默认另跑完整采集或创建日程。

整合前按本轮所需分支读取工作清单中的最新基线与实际运行记录，区分已核验日期、未复查、访问失败和未覆盖。岗位最近一批输入不等于完整账本；雷达最新目录聚合历史材料，不表示本轮全部重读。历史查询沿账本或原始轮次记录定位，已有交接文件按路径复用。没有 JD 输入时不沿用历史 `job_context` 给本轮强行关联岗位。

扩充后的结果同时给出原范围变化与新来源贡献；固定配额采样可比较任务结构，不能推断公司需求强弱。个人项目建议继续按能力证据分层，不让新增名企数量代替适配判断。
